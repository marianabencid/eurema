## CASE 1 — FACTOR COMÚN

INTRO:
Explain visually that all terms share something in common.

Example:
6x + 9x²

Show visually:

* common numbers highlighted
* common variables highlighted
* arrows pointing to repeated factors

STEP-BY-STEP:

1. Identify common factor
2. Divide each term
3. Place remaining terms inside parentheses

Make the factoring process animated:

* common factor “pulls out”
* terms slide into parentheses

GUIDED EXAMPLE:
12x² + 8x

Interactive buttons:

* “Identificar factor”
* “Sacar factor”
* “Completar paréntesis”

PRACTICE:
Drag expressions into:

* “Tiene factor común”
* “No tiene factor común”

Instant feedback:

* green glow for correct
* shake animation for incorrect

---

## CASE 2 — DIFERENCIA DE CUADRADOS

Use:
a² - b² = (a+b)(a-b)

VISUAL EXPLANATION:
Show:

* both terms as perfect squares
* square roots appearing visually
* subtraction sign highlighted in red

GUIDED EXAMPLE:
x² - 49

Interactive flow:

1. Click each square root
2. Build both parentheses
3. Choose signs

Animation:
parentheses assemble dynamically.

PRACTICE:
Match expressions to their factorized forms.

---

## CASE 3 — TRINOMIO CUADRADO PERFECTO

Formula:
a² + 2ab + b² = (a+b)²

This section should be VERY visual.

Show:

* roots of first and last terms
* multiplication animation
* “2ab” verification

Interactive sequence:

1. Student selects roots
2. System multiplies them
3. Multiply by 2
4. Verify middle term

If correct:
show:
“¡Sí coincide!”

If incorrect:
show:
“El término del medio no coincide.”

GUIDED EXAMPLE:
a² + 4a + 4

Animate:
(a+2)² assembling visually.

PRACTICE:
Students identify whether expressions ARE or ARE NOT TCP.

---

## CASE 4 — TRINOMIO x² + bx + c

Explain visually:
Find two numbers that:

* multiply to c
* add to b

Use interactive number cards.

GUIDED EXAMPLE:
x² + 5x + 6

Student clicks number pairs.

Correct pair:
2 and 3

Then:
automatically construct:
(x+2)(x+3)

PRACTICE:
Multiple draggable number pair exercises.

---

## CASE 5 — TRINOMIO ax² + bx + c

This should be more guided because it is harder.

Use step-by-step decomposition method.

GUIDED EXAMPLE:
2x² + 7x + 3

Flow:

1. Multiply a*c
2. Find numbers
3. Split middle term
4. Group visually
5. Factor by grouping

VERY IMPORTANT:
Color-code grouped terms.

Animate:
grouping brackets appearing.

PRACTICE:
Students arrange shuffled steps in correct order.

---

## CASE 6 — SUMA Y DIFERENCIA DE CUBOS

Use:
a³ + b³ = (a+b)(a²-ab+b²)
a³ - b³ = (a-b)(a²+ab+b²)

VISUAL EXPLANATION:
Show cube roots emerging from terms.

GUIDED EXAMPLE:
x³ + 8

Interactive sequence:

1. Identify cube roots
2. Build first parentheses
3. Construct second parentheses
4. Choose correct signs

IMPORTANT:
Explain sign pattern visually using color coding.

PRACTICE:
Sign-selection challenge.
